# Repository working instructions

## Delivery cadence

Owner directive: commit, merge and push after every **10 completed, verified improvements**.

- Count one user-visible improvement or resolved finding as one item. Supporting code, tests and documentation for that item count together, not separately. Track completed items in the working plan.
- At 10 items, finish the relevant checks, commit the batch, integrate it into `main`, and push `main` to `origin` before starting the next batch.
- Push any smaller remainder when the requested work finishes or the owner asks for an immediate update. Do not invent changes or empty commits to reach ten.
- Preserve unrelated local edits and the repository's visibility. Do not force-push or bypass failing checks. Report a concrete blocker if a batch cannot be published.
