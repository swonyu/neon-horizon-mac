# Repository critique and repair record — 12 September 2026

Reviewed the complete repository at `3df2c1e`, including every tracked script,
control, preset, document, test, source image and generated wallpaper asset.
Installer and artwork reviews ran independently, followed by integration checks.
The [implementation plan](plans/2026-09-12-audit-fixes.md) records the work order.

## Overall assessment

The small architecture fits the product: a portable HTML painting, a standard-library
preference tool, optional native automation, and explicit manual setup steps.
There is no reason to add an application framework, package manager or custom
clipboard database. The strongest existing features are per-key undo, protection
of later edits, offline artwork, loopback-only serving, and an inert configuration
until the owner chooses to enable it.

The baseline checks passed, but missed failures at the command boundaries: a
fresh plan could replace the one shown, undo could read an incomplete journal,
and a partially installed login host could appear complete. The artwork was
reproducible with the reference build environment, but three visible behavior
defects were provable from the source. Several mathematical and performance
claims went further than the measurements supported.

## Artwork critique

The sunset and its river reflection make a clear focal point. Darkening the
foreground restored the intended hierarchy: the existing embedded image measured
promenade p95 **127.0**, promenade p05 **1.5**, sky p95 **155.5**, and sky mean
**89.3** in the audit environment. The four seeded rain tiles reach their intended
drop counts, and the near-plane mask geometry matches the painted parapet.

The reflection placement, calm interaction and reduced-motion brightness have
specific fixes. The other aesthetic concerns need a rendered review before
redesign: the wide-display breakpoint intentionally changes scale abruptly,
and several eased motions still reach zero velocity at keyframes. Neither is
evidence that the scene looks bad. Claims that they are mathematically continuous
or never dwell have been removed rather than changing unviewed choreography.

The original asset rebuild matched all three embedded WebPs byte for byte and
the static PNG pixel for pixel with Python 3.12, NumPy 2.3.5, Pillow 12.3.0 and
libwebp 1.6.0. Encoder versions can change bytes. The still is a representative
painting, not a captured animation frame.

## Evidence and boundaries

Baseline Python and Lua checks passed before edits. Reproductions then exercised
the command-level races, partial installation, foreign label collision,
repeated build and reflection coordinates. The integrated checks passed on macOS 27.0 build 26A428. Verification covers:

- Python: command-level preview/undo races, confirmation cancellation, exact-value
  validation, journal synchronization failure, chronological backups, and launcher
  behavior with missing/failing Python and literal backup paths.
- Native macOS preference adapter: actual apply, readback and conflict-safe undo
  in a new disposable domain, removed after the check.
- Host: 13 recovery checks, including malformed/foreign files and jobs, missing
  assets, publication failure, exact HTTP readiness, immediate port reuse after
  shutdown, and active-listener refusal. Service commands are mocked; loopback
  HTTP and file operations are real.
- Wallpaper: reflection coordinates, reduced-motion baseline, deterministic
  repeated builds, missing-asset and publication failures, and rejected-grade
  preservation with the reference image libraries.
- Node: the generated page’s actual script with a mocked document, testing hidden
  and visible states plus adding/removing the calm fragment without reload.
- Lua: 18 edge scenarios plus invalid configuration; all eight shortcuts,
  preservation of existing bindings, and four shortcut startup failure paths.
- Native icon generator: four 1024 × 1024 PNGs produced in a temporary folder.
  No folder’s icon was changed. Terminal profile properties were inspected.
- Package checks: offline asset structure, privacy scan, nested documentation
  links, and whitespace validation. Final source is packaged from its local commit.

The independent follow-up review also found native float rounding and a
post-shutdown port-probe failure. Both were reproduced, repaired and added to
regression coverage before completion.

The review did not apply the preset to personal UI domains, install a login
service, enable Hammerspoon or replace a running desktop. Native adapter tests
use a disposable preference domain. Launchd and Hammerspoon lifecycle checks
use mocks. An existing browser security block prevented a fresh rendered preview
and was respected. Frame time, power use, actual Accessibility-controlled Space
switching and a login/reboot on a second Mac remain live verification tasks.

The Terminal profile contains visual properties only; the icon generator uses
native symbols locally. No new defect was established in their behavior, the
source images, rain encoding, loopback route allowlist or existing later-edit
preservation. Manual-only settings remain explicit choices because transferring
whole preference files would replace each recipient's own setup.
